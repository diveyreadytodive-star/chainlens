HOW IT WORKS

원본에서 영수증까지,
한 단계씩 확인합니다.

지갑 연결, 로그인, 서명이나 거래 실행 없이 공개 거래 기록만 읽습니다.

  1. 01

    거래 입력

    Ethereum 거래 해시 또는 지원 탐색기 링크를 붙여 넣습니다.

  2. 02

    결정론적 사실 추출

    거래·영수증·표준 Transfer/Approval 로그에서 수량, 주소, 수수료, 상태를 분리합니다.

  3. 03

    검증된 설명

    AI는 사실을 대체하지 않고 낯선 용어를 짧게 풀어 설명합니다. 연결이 불안정해도 기본 해설을 유지합니다.

  4. 04

    원본 근거 확인

    각 결과에서 원본 거래, 영수증, 로그와 조회 시점을 직접 확인할 수 있습니다.

ROADMAP

Ethereum Mainnet에서 검증한 근거 중심 해석 패턴을 다른 체인과 자산 표준으로 넓혀갑니다. 체인 지원을 넓히는 일은 현재 범위를 과장하는 일이 아니라, 각 체인별 원본 근거와 한계를 새로 정의하는 일입니다.

확장 설치 전 확인

이 ZIP은 공개 ChainLens API에 연결됩니다. 아직 Chrome Web Store에 등록하지 않아 개발자 모드 설치가 필요합니다. API 키는 ZIP이나 브라우저에 포함하지 않으며, Groq 키는 서버 환경변수에만 둡니다.
